结果怎么理解？

“网站配置检查”读取当前页面 HTTP、robots 指令和 canonical，不运行页面 JavaScript，也不评估 robots.txt 规则。不能由此确定 Google 是否收录。

“Google 收录检查”读取官方 URL Inspection API 保存的索引记录，不是实时可收录测试，不能自动请求索引。

反馈页 noindex、HTTP 或 www 跳转、备用版本可能正常。黄色表示需要查看，不等于必须修复。

每次每站最多 500 页，最多读取 30 个同域名 XML 站点地图；暂不支持 gzip。API 检查遇到错误会中断该站，保留已完成结果。

本地运行 · 不使用 AI API · 数据保存在你的电脑。当前版本手动检查；历史保留，不包含后台定时任务。
